ORIS API (1.0.0)

Download OpenAPI specification:

Neoficiální OpenAPI specifikace ORIS API (informační systém Českého svazu orientačních sportů), sestavená podle oficiální dokumentace https://oris.orientacnisporty.cz/API.

API je ve skutečnosti jediný endpoint /API/, kde se volaná metoda určuje query parametrem method. Pro přehlednost je zde každá metoda uvedena jako samostatná cesta ve tvaru /API/?method=<název> – parametr method proto není deklarován samostatně, je součástí cesty. (Query string v klíči cesty je mimo striktní OpenAPI standard, dokumentační nástroje jej však běžně zobrazí správně.)

Formát odpovědi: primárně json; podporovány jsou i xml a xml2 (xml2 vrací stejné názvy XML nódů pro opakující se hodnoty).

Není-li uvedeno jinak, komunikace probíhá GET požadavkem. Metody označené jako POST přijímají parametry ve formě application/x-www-form-urlencoded.
